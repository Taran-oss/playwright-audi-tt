# Вимога: додавання автомобіля Audi TT у Garage

## Початковий стан

- Користувач відкрив QAuto та увійшов через Guest log in.
- Після входу відкрито розділ Garage (ліве меню, пункт Garage).
- На сторінці доступна кнопка Add car.

## Сценарій

1. Натиснути кнопку Add car.
2. Переконатися, що відкрилося модальне вікно Add a car.
3. У полі Brand обрати Audi.
4. У полі Model обрати TT.
5. У поле Mileage ввести 12000.
6. Натиснути Add.

## Очікуваний результат

- Модальне вікно Add a car закривається без повідомлень про помилку.
- У списку Garage з'являється картка автомобіля з назвою Audi TT.
- У картці Audi TT відображається пробіг 12000.
- Кількість автомобілів у Garage збільшилась на один порівняно з початковим станом.

## Межі

- Model залежить від Brand: список моделей стає актуальним лише після вибору Audi.
- Кнопка Add має бути активною лише після заповнення всіх полів; валідацію порожніх і некоректних значень Mileage цей кейс не перевіряє.
- Перевіряється додавання й відображення автомобіля в Garage, а не редагування, видалення чи додавання витрат пального.
- Guest-сесія тимчасова: дані можуть не зберігатися після виходу або перезавантаження, тому перевірка виконується в тій самій сесії.
- Точні HTML-атрибути й CSS-класи не задані; ознаки елементів (назви полів Brand, Model, Mileage, кнопок Add car, Add, Cancel) треба підтвердити за поточним UI.
- Якщо Audi або TT немає у списках, кнопка Add недоступна чи UI відрізняється від вимоги, треба зафіксувати blocker, а не вигадувати успішний результат.

## Візуальний приклад

Окремого скриншота для цього сценарію немає. `requirements/instructions-search.png` показує сторінку Instructions (пошук Audi → TT) і до додавання автомобіля в Garage не належить; не використовуйте його як джерело очікувань для цього кейсу.
